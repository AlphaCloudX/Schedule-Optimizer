Your Better Than Web Advisor Course Scheduler



How Does This Work?

Step 1: Enter Course Codes

Enter the course codes in any of the following formats: COURSE*CODE (e.g., CIS*2750), Course Code (e.g., CIS 2750), or CourseCode (e.g., CIS2750). Separate each course by a comma, and only enter courses for the next semester (Winter25).

Proper Entry Examples:

  • CIS*2750, CIS*3110, CIS*3190
  • CIS 2750, CIS 3110, CIS 3190
  • CIS2750, CIS3110, CIS3190
  • CIS*2750, CIS 3110, CIS3190
Step 2: Set Earliest and Latest Times (Optional, Leave Blank if not needed)

Choose the earliest time you plan to be on campus and the latest time you plan to leave.

Step 3: Generate Schedule

Click the 'Generate Schedules' button, and the tool will create possible schedules.
