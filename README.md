# University of Guelph Course Selection Optimizer

A Python script designed to optimize your course layout by minimizing the time between your classes.

---

## Features

- **Flexible Input:** Enter any number of courses for optimization.
- **Time Constraints:** Set earliest and latest class preferences.
- **Lightweight:** Only requires Flask for the web app.
- **DE Class Support:** Easily incorporate distance education classes.
- **Free and Open Source:** Completely free to use and customize.

---

## Getting Started

### Prerequisites

- Python 3.x installed on your system.
- Flask library installed. You can install Flask using pip:
  ```bash
  pip install flask
  ```

### Running the Project

1. Clone the repository:
   ```bash
   git clone https://github.com/AlphaCloudX/Schedule-Optimizer.git
   ```
2. Navigate to the project directory:
   ```bash
   cd Schedule-Optimizer
   ```
3. Run the Flask server:
   ```bash
   python Main.py
   ```
4. Open your browser and navigate to `http://127.0.0.1:5000` to use the application.
